# 🌸 Portafolio Personal | Alexandra Del Valle

Portafolio personal en desarrollo, creado para presentar mis habilidades, proyectos y crecimiento como **Desarrolladora Junior Full-Stack**.

La propuesta combina tecnología, creatividad y diseño, con una estética **Cozy / Cottagecore y Pixel Art**, inspirada en interfaces de videojuegos.

## 🎮 Secciones

- **Portada:** presentación y bienvenida.
- **Selección de personaje:** avatar y perfil personal.
- **Mi perfil:** información profesional y habilidades blandas.
- **Skills:** habilidades técnicas.
- **Proyectos:** trabajos y desarrollos realizados.
- **Contacto:** medios de comunicación.

## 🛠️ Tecnologías previstas

HTML5 · CSS3 · JavaScript · Bootstrap 5
